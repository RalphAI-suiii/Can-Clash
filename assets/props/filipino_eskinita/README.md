Filipino Eskinita obstacle sprites
==================================

Transparent RGBA assets based on the upper-right Filipino Eskinita panel of the supplied Can Clash concept image. These are AI-recreated props, not pixel-perfect cutouts from the concept art.

`filipino_eskinita_obstacles_sheet.png` is a 4 x 3 grid of 544 x 384 cells. See `sprite_manifest.json` for names, cell coordinates, and tight bounds. Individual transparent PNGs are provided for scene use.
