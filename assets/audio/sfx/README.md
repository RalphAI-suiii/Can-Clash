# Map-selection sound

`Spinning Wheel Sound Effect - A.B.S. Playz.mp3` was supplied by the user in the background-music Drive folder and imported on 2026-10-25:
https://drive.google.com/file/d/11_lWITuJ4V_mfBmzZ5QLj764jxTK8J3_/view

Original filename and MP3 bytes are preserved. Native Godot playback skips the 1.5-second silent lead-in and runs at 1.84× speed so the source's 10.7-second ending cue aligns with the five-second map reveal. The ending cue plays over the selected-card hold; playback stops before the match opens at 6.3 seconds, or immediately if the selection screen closes early.

Each PC plays the effect locally once per selection screen. The scene owns the AudioStreamPlayer; lobby music continues on its existing Music bus. Effect volume defaults to -10 dB and is editable in the selection scene's Inspector.

## Match cues

`throwoff_title.wav`, `throwoff_tick.wav`, `throwoff_go.wav`, and `can_hit.wav`
are original cartoon cues generated by `generate_match_sfx.py`. The title cue's
accent lands as the opening text finishes sliding in. The last three seconds
of the run to the line show and sound 3, 2, 1; the go cue plays when throw
input opens. A can impact plays once when the host-confirmed can state changes
from standing to toppled. Its level and pitch follow the impact strength sent
in the can snapshot, so LAN joiners hear the same stronger or softer hit.
These short cues play locally over the existing match music.
